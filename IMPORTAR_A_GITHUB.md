Rama recomendada:

`work/unity-migration-phase1-v0.1.0`

## Opción PowerShell

Desde la carpeta del proyecto ejecuta `PUBLICAR_GITHUB.ps1`.

El script no contiene credenciales. Utiliza la autenticación Git/GitHub que ya exista en el PC.

## Unity Hub

No abras una subcarpeta. Selecciona la carpeta que contiene simultáneamente:

- `Assets/`
- `Packages/`
- `ProjectSettings/`

Esa carpeta es la raíz del proyecto Unity.
